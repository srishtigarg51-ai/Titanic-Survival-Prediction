Deep Neural Network Architecture

Engineered specifically for structured tabular data. Unlike standard multi-layer perceptrons which are prone to overfitting on small tabular samples, this model employs Residual Skip Connections, Batch Normalization, SiLU (Swish) activations, and Dropout regularization.

Input Layer (23 Features)
Demographics, Pclass One-Hot, Scaled Fare & Age, Family Size, Interaction flags
Dense Projection + BatchNorm1d + SiLU + Dropout(0.20)
Linear(23, 64) -> Normalized Feature Embeddings
Residual Block (Skip Connection)
Linear(64, 64) -> BatchNorm -> SiLU -> Dropout(0.25) -> Linear(64, 64) + Identity Skip
Compression Block
Linear(64, 32) -> BatchNorm -> SiLU -> Dropout(0.20) -> Linear(32, 16) -> SiLU
Classification Head: Linear(16, 1) + Sigmoid
Binary Survival Probability [0.0 - 1.0]
